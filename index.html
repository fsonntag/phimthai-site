How It Works

Simply type Thai words using English letters. PhimThai will suggest Thai words as you type:

sawatdee → สวัสดี (hello)
aroy → อร่อย (delicious)
kao → เข้า, ข้าว (enter, rice)
pom → ผม (I/me)
gin → กิน (eat)

Select the correct word from the candidate window, just like typing Chinese with Pinyin.
