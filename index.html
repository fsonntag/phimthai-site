Installation

  1. Download PhimThai-1.0.pkg using the button above
  2. Open the downloaded file and follow the installer
  3. Open System Settings (or System Preferences on older macOS)
  4. Navigate to Keyboard → Input Sources
  5. Click the + button at the bottom left
  6. Search for "Thai - Phonetic" and add it
  7. Switch to PhimThai from the menu bar and start typing!

How It Works

Simply type Thai words using English letters. PhimThai will suggest Thai words as you type:

sawatdee → สวัสดี (hello)
aroy → อร่อย (delicious)
kao → เข้า, ข้าว (enter, rice)
pom → ผม (I/me)
gin → กิน (eat)

Select the correct word from the candidate window, just like typing Chinese with Pinyin.
