Frequently Asked Questions

How do I type Thai words?

Type Thai words using English letters (romanization). For example:

  • Type sawatdee → select สวัสดี
  • Type aroy → select อร่อย
  • Type kao → choose between เข้า or ข้าว

PhimThai shows candidate words as you type. Select the correct one from the suggestion bar.

What's the difference between free and premium?

Free tier: 7-day unlimited trial, then 50 Thai words per day.

Premium (one-time purchase): Unlimited typing forever.

English typing works the same in both tiers.

Does PhimThai require internet access?

No. PhimThai works completely offline. See our Privacy Policy for details.
