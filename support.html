Frequently Asked Questions

How do I enable the keyboard?

macOS:

  1. Open System Settings (or System Preferences)
  2. Go to Keyboard → Input Sources
  3. Click the + button
  4. Search for "Thai - Phonetic" and add it
  5. Use the menu bar flag icon to switch keyboards

iOS/iPadOS:

  1. Open Settings → General → Keyboard → Keyboards
  2. Tap "Add New Keyboard"
  3. Select "PhimThai"
  4. When typing, tap the globe icon to switch keyboards

Android:

  1. Open Settings → System → Languages & input
  2. Tap "On-screen keyboard"
  3. Enable "PhimThai"
  4. When typing, tap the keyboard switcher icon

How do I type Thai words?

Simply type Thai words using English letters (romanization). For example:

  • Type sawatdee → select สวัสดี
  • Type aroy → select อร่อย
  • Type kao → choose between เข้า or ข้าว

PhimThai will show candidate words as you type. Select the correct one from the suggestion bar.

What's the difference between free and premium?

Free tier: Type up to 300 Thai words per day. Perfect for casual learners and light usage.

Premium ($2.99 one-time): Unlimited typing. No daily limits. Support development.

Note: English typing and all other features work the same in both tiers.

How is the word count calculated?

Only Thai words are counted toward your daily limit. English words, numbers, and punctuation don't count. The counter resets at midnight (local time) each day.

You can view your current count in the PhimThai app settings.

Does PhimThai require internet access?

No! PhimThai works completely offline. All Thai dictionaries and processing happen on your device. No data is ever sent to our servers (we don't even have servers).

Is my typing data collected?

Absolutely not. PhimThai collects zero data. We never see what you type, where you type it, or any other information. See our Privacy Policy for details.

Can I use PhimThai in all apps?

Yes! PhimThai works as a system-wide keyboard, so you can use it in any app that accepts text input: Messages, Mail, Safari, Notes, social media apps, etc.

I purchased premium but it's not working

  1. Open the PhimThai app
  2. Go to Settings
  3. Tap "Restore Purchases"
  4. Wait a few seconds for verification

Android:

  1. Open the PhimThai app
  2. Go to Settings
  3. Tap "Restore Purchase"
  4. Your premium status should restore automatically

If this doesn't work, please contact support with your purchase receipt.

The keyboard isn't showing candidate suggestions

Make sure you're typing in lowercase English letters. Try these steps:

  1. Type slowly and wait for candidates to appear
  2. Try common words like sawatdee or aroy
  3. Make sure you're using the PhimThai keyboard (check the keyboard switcher)
  4. Try deleting and reinstalling the app

If the problem persists, please contact support.

Can I use different romanization systems?

PhimThai currently uses a phonetic romanization system that handles common variants. Support for multiple romanization systems (Royal Thai, Paiboon, etc.) is planned for future updates.

How do I uninstall PhimThai?

macOS:

  1. Open System Settings → Keyboard → Input Sources
  2. Select "Thai - Phonetic" and click the - button
  3. Open Finder → Go → Go to Folder
  4. Type /Library/Input Methods
  5. Drag PhimThai to Trash
  6. Restart your Mac

iOS/Android:

Uninstall like any other app (long-press icon → Delete/Uninstall).

Troubleshooting

macOS: "Cannot be opened because it is from an unidentified developer"

This means the app isn't notarized yet (we're working on it!). To install anyway:

  1. Right-click (or Control+click) on the installer
  2. Select "Open"
  3. Click "Open" in the dialog

iOS: Keyboard not appearing in Settings

  1. Make sure you've opened the PhimThai app at least once
  2. Restart your iPhone/iPad
  3. Go to Settings → General → Keyboard → Keyboards
  4. Look for PhimThai in the list

Android: Keyboard crashes when typing

  1. Go to Settings → Apps → PhimThai
  2. Tap "Force Stop"
  3. Clear cache (not data)
  4. Re-enable the keyboard

If crashes persist, please report the issue with your device model and Android version.
