PhimThai for macOS

How do I open PhimThai?

The PhimThai companion app is installed in /Applications and can be opened through:

  • Applications folder
  • Spotlight search (Cmd+Space, then type "PhimThai")
  • Launchpad

"Show Input menu in menu bar" is not required to use PhimThai.

How do I enable the keyboard?

  1. Open PhimThai from Applications.
  2. Click "Open Keyboard Settings."
  3. Open or edit Input Sources.
  4. Select Thai.
  5. Add "Thai – Phonetic."
  6. Switch to it with Control–Space.

The keyboard does not appear

If Thai – Phonetic does not appear in your input sources:

  1. Confirm the installer completed successfully.
  2. Open PhimThai from Applications and try clicking "Open Keyboard Settings" again.
  3. Check System Settings → Keyboard → Text Input → Input Sources.
  4. Log out of macOS and log back in once (this is often needed for input methods to appear).
  5. If it is still missing, please report your macOS version and Mac processor type (Apple Silicon or Intel).

How do I uninstall PhimThai?

To uninstall PhimThai on macOS:

  1. Download the uninstaller.
  2. Open the uninstaller and follow the instructions.
  3. Log out and back in if Thai – Phonetic remains visible temporarily.

Is the macOS version free?

PhimThai for macOS is free during the beta. The iOS and Android versions have their own trial and purchase terms.

Reporting a Mac problem

When reporting an issue on macOS, please include:

  • Mac model
  • Apple Silicon or Intel
  • macOS version
  • PhimThai version
  • Affected application (where you were typing)
  • Romanized text you entered
  • Expected and actual Thai output
  • Screenshot, if relevant

Frequently Asked Questions

How do I type Thai words?

Type Thai words using English letters (romanization). For example:

  • Type sawatdee → select สวัสดี
  • Type aroy → select อร่อย
  • Type kao → choose between เข้า or ข้าว

PhimThai shows candidate words as you type. Select the correct one from the suggestion bar.

What's the difference between free and premium?

Free tier: 7-day unlimited trial, then 50 Thai words per day.

Premium (one-time purchase): Unlimited typing forever.

English typing works the same in both tiers.

Does PhimThai require internet access?

No. PhimThai works completely offline. See our Privacy Policy for details.
